# Quran Quest

A React + Phaser game designed as an educational mobile-friendly platformer.

## Overview
This game is built with React and Phaser, with a mobile-first approach for touch controls and smooth gameplay. Players move through levels, avoid obstacles, collect rewards, and progress through the experience in a simple but immersive way.

## Features
- React-based front-end
- Phaser-powered gameplay
- Mobile-friendly controls
- Smooth character movement and jumping
- Checkpoints and respawn system
- Responsive UI for desktop and mobile
- APK-ready mobile build support

## Tech Stack
- React, Vite, Phaser, TypeScript, Capacitor

## Installation
1) Install dependencies: `npm install`
2) Run locally: `npm run dev`
3) Build for production: `npm run build`

## Android APK
Run `npx cap sync android`, then open Android Studio to build the APK.
